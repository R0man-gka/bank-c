# Банковская система на C

Простая банковская система написанная на C с хранением данных в бинарном файле.

## Возможности
- Регистрация пользователя с логином и PIN-кодом
- Система авторизации
- Пополнение и снятие средств
- Проверка баланса
- Данные хранятся в бинарном файле
- Выбор счёта

## Типы счетов
- SAVINGS — сберегательный
- CHECKING — расчётный
- SOCIAL — социальный

## Сборка
gcc main.c Bank.c -o bank

## Запуск
.\bank

## Использование
1. Запустить программу
2. Выбрать: есть аккаунт (1) или создать новый (2)
3. Если новый: ввести логин, PIN, название счёта и тип
4. Если есть: ввести логин и PIN
5. Выбрать операцию: пополнить, снять или выйти

## Файлы
- `main.c` — точка входа
- `Bank.c` — банковские функции
- `Bank.h` — структуры и объявления
